# 📚 Implementing Stack and Queue

## 📌 About

The Stack and Queue Implementation project is a console-based Python project developed to understand two fundamental linear data structures. The project demonstrates the implementation of stacks and queues using different approaches and applies these concepts to practical problems such as balanced parentheses checking and task scheduling.

## 🎯 Problem Statement

Develop Python programs to understand and implement Stack and Queue data structures using different approaches. The project should demonstrate their basic operations and practical applications through balanced parentheses checking and task scheduling.

The project includes:

- Implementing a Stack using a Python list
- Implementing a Stack using a linked list
- Implementing a Queue using a Python list
- Implementing a Circular Queue
- Checking balanced parentheses using a stack
- Implementing a task scheduler using a queue

## ✨ Features

### 📚 Stack Operations

- Implement Stack using Python List
- Implement Stack using Linked List
- Perform push, pop, and peek operations
- Check whether the stack is empty
- Follow the LIFO principle

### 🔄 Queue Operations

- Implement Queue using Python List
- Implement Circular Queue
- Perform enqueue, dequeue, and peek operations
- Check empty and full conditions
- Follow the FIFO principle

### 🧩 Practical Applications

- Balanced Parentheses Checker
- Task Scheduler using Queue
- Process tasks in FIFO order
- Validate matching parentheses using Stack

## 📁 Project Files

### 📄 stack_list.py

Implements a Stack using a Python list and demonstrates push, pop, peek, and empty-check operations following the LIFO principle.

### 📄 stack_linkedlist.py

Implements a Stack using linked list nodes and performs stack operations from the top of the linked list.

### 📄 queue_list.py

Implements a Queue using a Python list and demonstrates enqueue, dequeue, peek, and empty-check operations following the FIFO principle.

### 📄 circular_queue.py

Implements a Circular Queue using a fixed-size list with front and rear pointers. It handles enqueue, dequeue, peek, empty, and full conditions.

### 📄 balanced_parenthesis.py

Checks whether an expression contains balanced parentheses by using a stack to match opening and closing brackets.

### 📄 task_scheduler.py

Implements a simple task scheduler using a queue. Tasks are added and processed in the same order using the FIFO principle.
