# 🎓 Student Record Management System

## 📌 About

The Student Record Management System is a console-based Python application that allows users to add, store, and display student records using text files. The application demonstrates Python file handling, exception handling, input validation, and menu-driven programming through a practical real-world example.

---

## 🎯 Problem Statement

Develop a Python application that enables users to efficiently manage student records using file handling. The application should allow users to:

- Add new student records
- Store student details in a text file
- Display all saved student records
- Validate user inputs
- Handle file-related exceptions
- Provide a simple menu-driven interface

---

## ✨ Features

### 👨‍🎓 Student Management

- ➕ Add student records
- 💾 Store records in a text file
- 📋 Display all stored student records

### ✅ Input Validation

- Validate student name
- Validate student age
- Validate GPA

### ⚠️ Exception Handling

- Handle File Not Found Exception
- Handle Empty File
- Handle Invalid Data Format
- Handle File Writing (IO Error)

### 🖥 User Interface

- Menu-driven console application
- Clean and formatted output
