# 🍽️ Recipe Organizer and Nutrition Calculator

## 📌 About

The Recipe Organizer and Nutrition Calculator is a console-based Python application that helps users organize recipes, search recipes by ingredients, and analyze nutritional information. It provides a simple menu-driven interface to manage recipe data while demonstrating the practical implementation of Python programming concepts.

---

## 🎯 Problem Statement

Develop a Python application that allows users to efficiently store and manage recipes. The application should enable users to:

- Add new recipes
- Store recipe details
- View all recipes
- Search recipes by ingredient
- Analyze nutritional information
- Display recipe statistics
- Handle invalid user inputs gracefully

---

## ✨ Features

- ➕ Add new recipes
- 📝 Store recipe name, ingredients, meal type, food type, and calories
- 📖 View all saved recipes
- 🔍 Search recipes by ingredient
- 📊 Calculate total number of recipes
- 📈 Calculate average calories
- 🥗 Count Vegetarian and Non-Vegetarian recipes
- 🔥 Display high-calorie recipes (more than 500 calories)
- 🌿 Display unique ingredients using Python sets
- ✅ Validate user inputs using exception handling
- 📋 Menu-driven console application
