# Mini Project 02 - Weather Stats Analyzer 🌤️

## 📖 About

The **Weather Stats Analyzer** is a console-based Python application developed as part of my Python Backend Development learning journey.

This project allows users to record daily temperatures, perform statistical analysis, convert temperatures between Celsius and Fahrenheit, and search previously recorded temperatures using Python collections.

It helped me apply multiple Python concepts together in a practical application while improving my problem-solving and logical thinking skills.

---

## 📝 Problem Statement

Weather data analysis often requires recording temperatures, performing statistical calculations, and converting temperature units accurately. Performing these tasks manually can be time-consuming and error-prone.

The objective of this project is to develop a console-based application that automates temperature recording, performs statistical analysis, supports temperature conversion, and enables quick temperature lookup using fundamental Python programming concepts.

## ✨ Features

- Records daily temperatures
- Validates user input
- Finds the highest and lowest temperature
- Calculates the average temperature
- Counts the number of days above average
- Converts Celsius to Fahrenheit
- Converts Fahrenheit to Celsius
- Stores day-wise temperatures using tuples
- Creates a set of unique temperatures
- Searches recorded temperatures
- Uses modular functions for better code organization
