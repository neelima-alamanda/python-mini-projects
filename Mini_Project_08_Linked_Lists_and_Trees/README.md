# 🔗 Linked Lists & Trees Exploration

## 📌 About

The Linked Lists & Trees Exploration project is a console-based Python project developed to understand advanced linear and hierarchical data structures. The project demonstrates the implementation of Singly Linked List, Doubly Linked List, Circular Linked List, and Binary Search Tree (BST) along with their fundamental operations.

The project also includes different tree traversal techniques and an algorithm to check whether a Binary Tree is balanced. It provides practical experience with Data Structures and Algorithms (DSA) concepts that are commonly used in software development and technical interviews.

## 🎯 Problem Statement

Develop Python programs to implement advanced data structures such as Singly Linked List, Doubly Linked List, Circular Linked List, and Binary Search Tree. The project should demonstrate insertion, deletion, searching, tree traversals, and checking whether a Binary Tree is balanced.

The project includes:

- Implementing Singly Linked List
- Implementing Doubly Linked List
- Implementing Circular Linked List
- Implementing Binary Search Tree
- Performing insertion, deletion, and search operations
- Performing different tree traversals
- Checking whether a Binary Tree is balanced

## 📁 Project Files

### 📄 singly_ll.py

Implements a Singly Linked List using nodes and supports insertion at the beginning, end, and specified position, deletion operations, and searching for an element.

### 📄 double_ll.py

Implements a Doubly Linked List where each node maintains links to both the previous and next nodes. It supports insertion, deletion, searching, and forward and backward traversal.

### 📄 circular_ll.py

Implements a Circular Linked List where the last node is connected back to the first node. It supports insertion, deletion, searching, and circular traversal.

### 📄 bst.py

Implements a Binary Search Tree and supports node insertion, deletion, searching, and Inorder, Preorder, Postorder, and Level-order traversals.

### 📄 balanced_binary_tree.py

Checks whether a Binary Tree is balanced by calculating the heights of the left and right subtrees and comparing their height differences.
