# 🚀 Python Backend Learning Journey using Flask

## 📌 About

The **Python Backend Learning Journey using Flask** project is a Flask-based web application developed to understand the fundamentals of Flask and basic backend development.

The project demonstrates Flask routing, Jinja2 template inheritance, static file handling, virtual environment setup, and CSS styling through a simple multi-page website.

The application presents a personalized Python Backend Learning Journey through three pages: **Home, About, and Contact**.

## 🎯 Problem Statement

Develop a simple multi-page web application using Flask to understand the basics of Python backend development. The project should demonstrate Flask routing, reusable HTML templates, static file management, and responsive CSS styling.

The project includes:

* Creating a Flask application structure
* Implementing multiple routes
* Using Jinja2 template inheritance
* Managing static CSS files
* Creating Home, About, and Contact pages
* Building a responsive user interface

## 📁 Project Files

### `app.py`

Main entry point of the Flask application. It imports the Flask application instance from the `app` package and starts the development server.

### `app/__init__.py`

Creates and configures the Flask application instance and imports the routes module so that the application's routes are registered.

### `app/routes.py`

Contains the application's route handlers for the Home, About, and Contact pages. Each route renders its corresponding HTML template.

### `app/templates/base.html`

Provides the common layout shared across all pages, including the navigation bar, content block, and footer. It uses Jinja2 template inheritance.

### `app/templates/home.html`

Defines the Home page of the application and introduces the Python Backend Learning Journey.

### `app/templates/about.html`

Displays the learning roadmap, including technologies already learned and technologies planned for the future.

### `app/templates/contact.html`

Provides contact options through Email, GitHub, and LinkedIn links.

### `app/static/style.css`

Contains the styling for the complete application, including the navigation bar, hero section, roadmap cards, contact cards, responsive layouts, and hover effects.

### `requirements.txt`

Contains the Python dependencies required to run the Flask application.

### `Python Backend Learning Journey using Flask.pdf`

Contains the detailed project documentation, including the Project Overview, Problem Statement, Features, Technologies Used, Project Structure, Python & Flask Concepts Used, Program Workflow, Output Screenshots, Learning Outcomes, and Conclusion.
