# Mini Project 01 - Student Grade Calculator 🎓

## 📖 About

The **Student Grade Calculator** is a console-based Python application developed to manage student records, calculate grades, determine pass/fail status, evaluate scholarship eligibility, and generate a detailed performance report.

This project demonstrates how fundamental Python concepts can be combined to build a practical application.

---

## 🎯 Project Objectives

- Collect student information
- Accept and validate subject marks
- Calculate total marks and percentage
- Determine grades and pass/fail status
- Check scholarship eligibility
- Generate a structured performance report
