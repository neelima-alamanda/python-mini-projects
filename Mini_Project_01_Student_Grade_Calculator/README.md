# Mini Project 01 - Student Grade Calculator 🎓

## 📖 About

The **Student Grade Calculator** is a console-based Python application developed as part of my Python Backend Development learning journey.

This project allows users to enter student details and subject marks, validates the input, calculates grades and performance statistics, determines pass/fail status and scholarship eligibility, and generates a well-formatted student performance report.

It helped me apply multiple Python concepts together in a practical application and strengthen my problem-solving skills through real-world implementation.

---

## 📝 Problem Statement

Educational institutions often require a simple and efficient way to evaluate student performance based on subject marks. Manually calculating grades, averages, and overall performance can be time-consuming and prone to errors.

The objective of this project is to develop a console-based application that automates the grade calculation process by collecting student information, validating inputs, calculating academic performance, assigning grades, and generating a structured report using fundamental Python programming concepts.

## ✨ Features

- Collects student information
- Accepts subject names and marks
- Validates user input
- Calculates total and average marks
- Determines subject-wise grades
- Identifies pass/fail status
- Calculates highest and lowest marks
- Displays grade distribution
- Checks scholarship eligibility
- Generates a formatted student report
- Displays appreciation notes based on performance
- Supports processing multiple students
- Uses modular functions for better code organization
